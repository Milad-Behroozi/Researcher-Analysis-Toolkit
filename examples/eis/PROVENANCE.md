# Provenance — synthetic EIS benchmark

These datasets are generated by `generate_synthetic_eis.py`, not measured.
Their purpose is to test circuit selection and parameter recovery when the
ground truth is known.

- Circuit: `R0-p(R1,CPE1)-p(R2,CPE2)`.
- Frequencies: 10⁶ to 10⁻² Hz, 81 logarithmically spaced points.
- Variants: noise-free and 3% independent Gaussian component noise.
- Seed: 20260723.
- Exact parameters and noise definition: `benchmark_metadata.json`.

The noisy case should be assessed using fit quality, bound hits, parameter
uncertainty/correlation, and physical plausibility together.
