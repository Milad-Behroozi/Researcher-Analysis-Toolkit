# License decision required before public release

No public reuse license has been selected for this release candidate. Until a
license is added, copyright law reserves reuse rights to the copyright holder.

Before making the repository public, the project owner should choose a license
that is compatible with all dependencies and institutional requirements. MIT or
BSD-3-Clause are common permissive choices for research software, but this is a
legal/project-governance decision and must be made by the owner.

After the decision, add the official license text as a root file named
`LICENSE` and update `CITATION.cff` and this README.
