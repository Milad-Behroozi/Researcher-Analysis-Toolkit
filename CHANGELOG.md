# Changelog

## 1.0.0-rc1 — 2026-08-22

- Added the graphical module launcher and isolated user environment workflow.
- Added electrochemical, photoelectrochemical, optical, spectroscopic, and
  publication-output modules.
- Added a Windows one-folder/Setup release workflow.
- Added automatic recovery from a virtual environment created by an
  incompatible Python version.
- Added experimental examples, reference outputs, and a deterministic synthetic
  EIS benchmark at 0% and 3% noise.
- Added provenance records, validation anchors, repository tests, and CI.
